# rickandmortyapi-spring-data-rest

A Spring Data REST application for exposing [rickandmortyapi-db](https://github.com/jinahya/rickandmortyapi-db).

## How to

Run the application.

```shell
$ ./gradlew bootRun
```

Open the hal explorer at http://localhost:8080/explorer/index.html#httpOptions=true&uri=/.

And/or open the swagger ui at http://localhost:8080/swagger-ui.html.
